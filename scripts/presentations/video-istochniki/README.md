# Видео модуля «Источники трафика» для AI-аватара (курс 94834)

Второй комплект по образцу пилота `video-baza`. Формат, шаблон слайдов и
правила начитки те же.

## Что здесь лежит

- `build.mjs`: сборка слайдов, 15 штук, формат 16:9
- `script.md`: текст начитки, разбитый по слайдам, около 940 слов (7 минут)
- `out/*.png`: готовые слайды, 3200x1800

## Чем это отличается от подробного конспекта

Комплекты `loom-detailed-*` это конспект на чтение: страница на каждый шаг
урока, рассчитано на PDF. Здесь другое: 15 слайдов под живую начитку, минимум
текста на слайде, потому что текст произносит аватар, а не читает студент.

Модуль большой, пятнадцать уроков. В презентацию вошли ключевые идеи по каждому
каналу, а не пересказ каждого урока: логика контекста и таргета, три
направления SEO, роль SMM, альтернативные источники, медийка и общий язык
метрик. Детали остаются в самих уроках.

## Правый нижний угол зарезервирован под аватара

В шаблоне это `AVATAR_SAFE_W/H` (420x420 в координатах 1600x900), примерно
четверть экрана в правом нижнем углу. Туда не должен попадать контент, иначе
аватар его перекроет.

Проверять глазами ненадёжно, поэтому есть скрипт:

```bash
python3 scripts/check_avatar_safe_zone.py scripts/presentations/video-istochniki/out
```

Он падает с ненулевым кодом, если хоть на одном слайде в эту зону заходит
контент. Здесь по той же причине, что и в пилоте, карта модуля сделана списком,
а не сеткой карточек: шесть каналов в два ряда карточек уходят под аватара.
Слайды с карточками держат один ряд из трёх штук.

## Как пересобрать

```bash
cd scripts/presentations/video-istochniki && node build.mjs
cd ../.. && node render_batch.mjs presentations/video-istochniki/out presentations/video-istochniki/out 1600 900
python3 check_avatar_safe_zone.py presentations/video-istochniki/out
```

## Дальше: HeyGen и заливка

1. Собрать видео в HeyGen: слайды из `out/` как фон, текст из `script.md`
   блоками по слайдам, аватар кружком в правом нижнем углу. Смена слайда должна
   совпадать с переходом к следующему блоку текста.
2. Залить готовый mp4 в урок:

```bash
python3 scripts/upload_lesson_video.py 1754511 путь/к/istochniki.mp4
```

`1754511` это урок «Видео модуля «Источники трафика»». Список остальных
уроков-контейнеров есть в шапке `upload_lesson_video.py`.

Важно: в этом уроке уже лежит старая заглушка примерно на 65 секунд. Загрузка
не заменяет существующее видео, а добавляет второе. После заливки нового ролика
старую заглушку нужно удалить руками через редактор урока на Stepik.
