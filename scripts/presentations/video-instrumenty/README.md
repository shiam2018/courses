# Видео модуля «Инструменты» для AI-аватара (курс 94834)

Второй комплект в этом формате, собран по образцу пилота `video-baza`.

## Что здесь лежит

- `build.mjs`: сборка слайдов, 15 штук, формат 16:9
- `script.md`: текст начитки, разбитый по слайдам, около 940 слов (7 минут)
- `out/*.png`: готовые слайды, 3200x1800

## Чем это отличается от `loom-detailed-instrumenty`

Тот комплект это подробный конспект под чтение в PDF. Здесь другое: 15 слайдов
под живую начитку, минимум текста на слайде, потому что текст произносит аватар,
а не читает студент.

Модуль большой, 15 уроков, поэтому в презентацию пошли только ключевые идеи:
выбор формата сайта, структура лендинга, конкуренты и SWOT, креативы и их
выгорание, аналитика, CRM, модели атрибуции, удержание и репутация, практика на
Tilda. Пересказа каждого урока здесь нет и не должно быть.

## Правый нижний угол зарезервирован под аватара

В шаблоне это `AVATAR_SAFE_W/H` (420x420 в координатах 1600x900), примерно
четверть экрана в правом нижнем углу. Туда не должен попадать контент, иначе
аватар его перекроет.

Проверять глазами ненадёжно, поэтому есть скрипт:

```bash
python3 scripts/check_avatar_safe_zone.py scripts/presentations/video-instrumenty/out
```

Он падает с ненулевым кодом, если хоть на одном слайде в эту зону заходит
контент. Карта модуля здесь сделана списком, а не сеткой карточек 3x2: шесть
карточек в два ряда не помещаются, нижний ряд уходит под аватара. Это уже
ловилось на пилоте.

## Как пересобрать

```bash
cd scripts/presentations/video-instrumenty && node build.mjs
cd ../.. && node render_batch.mjs presentations/video-instrumenty/out presentations/video-instrumenty/out 1600 900
python3 check_avatar_safe_zone.py presentations/video-instrumenty/out
```

## Дальше: HeyGen и заливка

1. Собрать видео в HeyGen: слайды из `out/` как фон, текст из `script.md`
   блоками по слайдам, аватар кружком в правом нижнем углу. Смена слайда должна
   совпадать с переходом к следующему блоку текста.
2. Залить готовый mp4 в урок:

```bash
python3 scripts/upload_lesson_video.py 1711843 путь/к/instrumenty.mp4
```

`1711843` это урок «Видео модуля «Инструменты»».

Важно: в этом уроке уже лежит старая заглушка на 58 секунд. Загрузка добавляет
второе видео, а не заменяет старое, поэтому после заливки нового ролика
заглушку нужно убрать руками через веб-интерфейс Stepik.
