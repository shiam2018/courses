# Видео модуля «Старт» для AI-аватара (курс 94834)

Второй комплект после пилота `video-baza`, сделан по тому же образцу: тот же
шаблон слайдов, та же логика начитки, та же проверка зоны аватара.

## Что здесь лежит

- `build.mjs`: сборка слайдов, 13 штук, формат 16:9
- `script.md`: текст начитки, разбитый по слайдам, около 880 слов (7 минут)
- `out/*.png`: готовые слайды, 3200x1800

## Откуда контент

`stepik-sync/94834/raw/01_Старт/`, все пять уроков модуля: кто автор, сколько
зарабатывает интернет-маркетолог, чему нужно научиться, что вас ждёт на курсе.
Ничего сверх этих уроков в слайдах нет.

## Чем это отличается от `loom-intro-start`

Тот комплект это вступительная нарезка под запись экрана. Здесь другое: 13
слайдов под живую начитку аватаром, минимум текста на слайде, потому что текст
произносит аватар, а не читает студент.

## Правый нижний угол зарезервирован под аватара

В шаблоне это `AVATAR_SAFE_W/H` (420x420 в координатах 1600x900), примерно
четверть экрана в правом нижнем углу. Туда не должен попадать контент, иначе
аватар его перекроет.

Проверять глазами ненадёжно, поэтому есть скрипт:

```bash
python3 scripts/check_avatar_safe_zone.py scripts/presentations/video-start/out
```

Он падает с ненулевым кодом, если хоть на одном слайде в эту зону заходит
контент. Карта модуля и уровни зарплат здесь специально сделаны списками, а не
сетками карточек: пять карточек уходят во второй ряд, а он попадает под аватара.

## Как пересобрать

```bash
cd scripts/presentations/video-start && node build.mjs
cd ../.. && node render_batch.mjs presentations/video-start/out presentations/video-start/out 1600 900
python3 check_avatar_safe_zone.py presentations/video-start/out
```

## Дальше: HeyGen и заливка

1. Собрать видео в HeyGen: слайды из `out/` как фон, текст из `script.md`
   блоками по слайдам, аватар кружком в правом нижнем углу. Смена слайда должна
   совпадать с переходом к следующему блоку текста.
2. Залить готовый mp4 в урок:

```bash
python3 scripts/upload_lesson_video.py 2541494 путь/к/start.mp4
```

`2541494` это урок «Видео-приветствие: что вас ждёт и сколько можно
зарабатывать», он уже существует и сейчас пустой. Список остальных
уроков-контейнеров есть в шапке `upload_lesson_video.py`.

Загрузка в урок, где видео уже есть, добавляет второе, а не заменяет старое.
У четырёх модулей лежат старые заглушки на 35-65 секунд, их нужно убрать
руками после заливки нового видео.
