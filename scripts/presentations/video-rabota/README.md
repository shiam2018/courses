# Видео модуля «Работа» для AI-аватара (курс 94834)

Второй комплект в формате, который обкатали на `video-baza`. Структура,
шаблон слайдов и правила текста те же.

## Что здесь лежит

- `build.mjs`: сборка слайдов, 15 штук, формат 16:9
- `script.md`: текст начитки, разбитый по слайдам, около 930 слов (7 минут)
- `out/*.png`: готовые слайды, 3200x1800

## Чем это отличается от `loom-detailed-rabota`

Тот комплект это подробный конспект под чтение в PDF: страница на каждый шаг
урока. Здесь другое: 15 слайдов под живую начитку, минимум текста на слайде,
потому что текст произносит аватар, а не читает студент.

## Что взято из модуля

Источник: `stepik-sync/94834/raw/05_Работа/`, 14 уроков. Слайды идут по логике
модуля: портрет кандидата, резюме, поиск вакансий, сопроводительное письмо,
три типа собеседований, тестовое задание, четыре практики.

Тема чувствительная, поэтому в начитке нет обещаний про гарантированное
трудоустройство. Сказано ровно то, что есть в уроках: поиск занимает от
полутора до трёх месяцев, отказы это часть процесса, модуль сокращает путь и
снимает типовые ошибки.

## Правый нижний угол зарезервирован под аватара

В шаблоне это `AVATAR_SAFE_W/H` (420x420 в координатах 1600x900), примерно
четверть экрана в правом нижнем углу. Туда не должен попадать контент, иначе
аватар его перекроет.

Проверять глазами ненадёжно, поэтому есть скрипт:

```bash
python3 scripts/check_avatar_safe_zone.py scripts/presentations/video-rabota/out
```

Он падает с ненулевым кодом, если хоть на одном слайде в эту зону заходит
контент. На этом комплекте карта модуля сразу сделана списком, а не сеткой
карточек 3x2: шесть карточек в два ряда не помещаются, нижний ряд уходит под
аватара. Отдельно пришлось укоротить подписи на слайдах `v07-where` и
`v11-interviews`: с описаниями в четыре строки нижняя граница карточек
задевала зону, скрипт показывал 0.2%.

## Как пересобрать

```bash
cd scripts/presentations/video-rabota && node build.mjs
cd ../.. && node render_batch.mjs presentations/video-rabota/out presentations/video-rabota/out 1600 900
python3 check_avatar_safe_zone.py presentations/video-rabota/out
```

## Дальше: HeyGen и заливка

1. Собрать видео в HeyGen: слайды из `out/` как фон, текст из `script.md`
   блоками по слайдам, аватар кружком в правом нижнем углу. Смена слайда должна
   совпадать с переходом к следующему блоку текста.
2. Залить готовый mp4 в урок:

```bash
python3 scripts/upload_lesson_video.py 1754512 путь/к/rabota.mp4
```

`1754512` это урок «Видео модуля «Работа»». Список остальных уроков-контейнеров
есть в шапке `upload_lesson_video.py`.

Важно: в этом уроке уже лежит старая заглушка на 47 секунд. Загрузка добавляет
в урок второе видео, а не заменяет старое, поэтому после заливки нужно зайти в
урок на Stepik и удалить заглушку руками. Через API этого шага нет.
