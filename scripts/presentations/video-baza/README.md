# Видео модуля «База» для AI-аватара (курс 94834)

Пилот формата. Если он подходит, остальные пять модулей делаются по этому же
образцу.

## Что здесь лежит

- `build.mjs`: сборка слайдов, 13 штук, формат 16:9
- `script.md`: текст начитки, разбитый по слайдам, около 800 слов (5-6 минут)
- `out/*.png`: готовые слайды, 3200x1800

## Чем это отличается от `loom-detailed-baza`

Тот комплект это подробный конспект: 55 страниц, по странице на каждый шаг
урока, рассчитан на чтение в PDF. Здесь другое: 13 слайдов под живую начитку,
минимум текста на слайде, потому что текст произносит аватар, а не читает
студент.

## Правый нижний угол зарезервирован под аватара

В шаблоне это `AVATAR_SAFE_W/H` (420x420 в координатах 1600x900), примерно
четверть экрана в правом нижнем углу. Туда не должен попадать контент, иначе
аватар его перекроет.

Проверять глазами ненадёжно, поэтому есть скрипт:

```bash
python3 scripts/check_avatar_safe_zone.py scripts/presentations/video-baza/out
```

Он падает с ненулевым кодом, если хоть на одном слайде в эту зону заходит
контент. На этом комплекте изначально попалась карта модуля карточками 3x2:
нижний ряд уходил под аватара, поэтому она переделана в список.

## Как пересобрать

```bash
cd scripts/presentations/video-baza && node build.mjs
cd ../.. && node render_batch.mjs presentations/video-baza/out presentations/video-baza/out 1600 900
python3 check_avatar_safe_zone.py presentations/video-baza/out
```

## Дальше: HeyGen и заливка

1. Собрать видео в HeyGen: слайды из `out/` как фон, текст из `script.md`
   блоками по слайдам, аватар кружком в правом нижнем углу. Смена слайда должна
   совпадать с переходом к следующему блоку текста.
2. Залить готовый mp4 в урок:

```bash
python3 scripts/upload_lesson_video.py 1713094 путь/к/baza.mp4
```

`1713094` это урок «Видео модуля «База»», он уже существует и сейчас пустой.
Список остальных уроков-контейнеров есть в шапке `upload_lesson_video.py`.

Загрузка в урок, где видео уже есть, добавляет второе, а не заменяет старое.
У четырёх модулей лежат старые заглушки на 35-65 секунд, их нужно убрать
руками после заливки нового видео.
