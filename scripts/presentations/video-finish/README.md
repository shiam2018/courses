# Видео модуля «Финиш» для AI-аватара (курс 94834)

Сделано по образцу пилота `video-baza`. Отличие в задаче: это не введение в
модуль, а финал курса. Слайды подводят итог всему пути, закрепляют, что студент
теперь умеет, и дают следующий шаг.

## Что здесь лежит

- `build.mjs`: сборка слайдов, 13 штук, формат 16:9
- `script.md`: текст начитки, разбитый по слайдам, около 730 слов (5-6 минут)
- `out/*.png`: готовые слайды, 3200x1800

## Откуда контент

`stepik-sync/94834/raw/06_Финиш/`: уроки «Что повторить», «Финальный тест»,
«Как оформить проект для портфолио», «Ура, вы закончили курс». Карта курса на
слайде 3 собрана из обзора модулей в уроке «Что повторить».

## Правый нижний угол зарезервирован под аватара

В шаблоне это `AVATAR_SAFE_W/H` (420x420 в координатах 1600x900), примерно
четверть экрана в правом нижнем углу. Туда не должен попадать контент, иначе
аватар его перекроет.

Проверять глазами ненадёжно, поэтому есть скрипт:

```bash
python3 scripts/check_avatar_safe_zone.py scripts/presentations/video-finish/out
```

Он падает с ненулевым кодом, если хоть на одном слайде в эту зону заходит
контент. На этом комплекте карта курса и блок «куда расти дальше» специально
сделаны в четыре карточки одним рядом: шесть карточек в два ряда не помещаются,
нижний ряд уходит под аватара. У слайда «Куда расти дальше» первая версия
задевала зону нижней границей карточек на 0.2%, описания сокращены до двух
строк.

## Как пересобрать

```bash
cd scripts/presentations/video-finish && node build.mjs
cd ../.. && node render_batch.mjs presentations/video-finish/out presentations/video-finish/out 1600 900
python3 check_avatar_safe_zone.py presentations/video-finish/out
```

## Дальше: HeyGen и заливка

1. Собрать видео в HeyGen: слайды из `out/` как фон, текст из `script.md`
   блоками по слайдам, аватар кружком в правом нижнем углу. Смена слайда должна
   совпадать с переходом к следующему блоку текста.
2. Залить готовый mp4 в урок:

```bash
python3 scripts/upload_lesson_video.py 1754514 путь/к/finish.mp4
```

`1754514` это урок «Мы у цели!», первый урок модуля «Финиш».

Важно: в этом уроке уже лежит старая заглушка на 35 секунд
(`6 Заключение - финал.mp4`). Загрузка добавляет второе видео, а не заменяет
старое, поэтому после заливки заглушку нужно убрать руками через веб-интерфейс
Stepik.
