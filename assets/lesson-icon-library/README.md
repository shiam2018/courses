# Lesson Icon Library

Библиотека решений для иконок уроков Stepik.

Стиль уже используется в проекте: `flat-color-icons` через Iconify, белый фон, квадратная обложка урока 180x180 после загрузки через `scripts/push_lesson_icons.py`.

## Правило для уроков "Полезные материалы"

Урок "Полезные материалы" лучше отмечать не общей иконкой книги, а иконкой рабочего пакета. Такой урок должен визуально читаться как место, где ученик забирает шаблоны, чек-листы, таблицы и финальный набор для применения после курса.

Базовые варианты:

- `opened-folder` - универсальная рабочая папка с материалами.
- `rules` - чек-листы, матрицы, критерии, правила принятия решений.
- `workflow` - процесс, сквозной проект, последовательность действий.
- `briefcase` - карьерные материалы, резюме, собеседования, портфолио.
- `document` - итоговый отчёт, файл, документ для сдачи.
- `todo-list` - список действий или контрольный чек-лист.
- `planner` - план, календарь, карта работы.

## Выбор для текущих уроков

- `183078 Основы SMM` -> `opened-folder`: стартовая рабочая папка SMM-специалиста.
- `183088 Профессия SMM` -> `rules`: шаблоны, матрица ответов, критерии решений.
- `183091 Creative Production` -> `workflow`: бриф, продакшен, тест, фидбек, отчёт как один процесс.
- `183103 Собеседование в маркетинге` -> `briefcase`: карьерный пакет для поиска работы.
- `183096 Профессия продакт-маркетолог` -> `planner`: рабочий план запуска от позиционирования до отчёта.

## Как применить

```bash
python3 scripts/push_lesson_icons.py assets/lesson-icon-library/useful-materials-icons.json
```

После применения подтянуть курсы:

```bash
python3 scripts/stepik_pull.py 183078
python3 scripts/stepik_pull.py 183088
python3 scripts/stepik_pull.py 183091
python3 scripts/stepik_pull.py 183103
```
