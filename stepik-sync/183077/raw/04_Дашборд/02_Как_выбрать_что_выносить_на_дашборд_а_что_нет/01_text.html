Что будет на уроке?

Дашборд — не копия таблицы с данными, а отбор: что из посчитанного действительно нужно, чтобы ответить на вопрос из первого модуля.

Правило отбора: на дашборд идёт только то, что напрямую отвечает на один из трёх под-вопросов («снижается ли», «за счёт чего», «стоит ли реагировать»). В файле-практикуме есть данные по всему сайту за май-август и по семи каналам /tools — если вынести на дашборд всё это без разбора, получится не дашборд, а копия исходной таблицы, которая ничем не помогает.

Для этого конкретного вопроса нужно: дневной темп по каждому каналу /tools за три месяца (отвечает на «снижается ли» и «за счёт чего») и абсолютные числа сеансов (отвечает на «стоит ли реагировать» — оценить масштаб). Данные по всему сайту cleanor.app (лист «Сайт по каналам») нужны один раз, как проверка общего контекста, а не как отдельная секция дашборда — это фон, а не главный экспонат.

Хорошо / плохо: дашборд из семи графиков, по одному на каждый канал и метрику из файла — плохо, потому что читатель не поймёт, куда смотреть в первую очередь. Один график с дневным темпом по каналам плюс одна строка с абсолютными числами — читается за 10 секунд и сразу показывает главное: Referral проседает, остальные каналы растут.
