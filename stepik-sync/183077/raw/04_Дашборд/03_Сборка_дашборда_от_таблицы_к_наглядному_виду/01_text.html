Что будет на уроке?

Сборка дашборда для этого проекта — три конкретных шага в файле-практикуме, без сложных инструментов.

  1. Сводная таблица. На листе «Данные по tools каналам» постройте сводную: строки — канал, столбцы — месяц, значения — сумма сеансов. Это даёт таблицу «канал × месяц» вместо длинного списка построчных записей.
  2. Столбец дневного темпа. Рядом со сводной добавьте вычисляемое поле или отдельные формулы: сеансы каждого месяца, делённые на число дней этого месяца (31 для июля, 23 для августа). Это тот же приём нормировки из модуля 2, применённый прямо внутри сводной таблицы.
  3. Диаграмма. Столбчатая диаграмма по дневному темпу, три группы столбцов (июнь/июль/август) на каждый канал. Именно такой тип диаграммы — из модуля курса «Excel с нуля» про выбор типа диаграммы под задачу — здесь подходит лучше линейного графика, потому что сравниваются отдельные каналы между собой, а не единый непрерывный тренд.

Частая ошибка на этом шаге: построить диаграмму по сырым суммам сеансов вместо дневного темпа — тогда неполный август снова визуально «занижает» все каналы разом, и вся работа модуля 2 по нормировке окажется незаметной на графике, хотя в таблице она есть.
