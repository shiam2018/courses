Полезные материалы

Здесь собраны шаблоны для сквозного проекта по Creative Production. Их можно использовать для следующей кампании, для работы с исполнителями или для упаковки портфолио-кейса.

1. Рабочий бриф

  • Продукт или услуга
  • Цель кампании
  • Целевая аудитория
  • Ключевое сообщение
  • Площадка размещения
  • Ограничения по бренду, закону, срокам и бюджету
  • Обязательные элементы
  • Данные, которых не хватает

2. Шаблон концепции

Гипотеза: аудиторию мотивирует [мотив]. Показываем [ситуация или образ]. Главная мысль: [сообщение]. Формат: [баннер, видео, сторис, пост]. Ожидаемое действие: [что должен сделать человек].

3. Постановка задачи исполнителю

  • Что нужно сделать
  • Для какой аудитории
  • Какая главная мысль
  • Какие форматы и размеры нужны
  • Какие материалы уже есть
  • Что нельзя использовать
  • Когда нужен первый черновик
  • Когда нужен финал

5. План теста

  1. Какие концепции сравниваем.
  2. Какая главная метрика решает победителя.
  3. Какие вторичные метрики смотрим.
  4. Какой минимальный объём данных нужен.
  5. Какие условия должны быть одинаковыми.
  6. Что делаем при каждом исходе теста.

6. Шаблон фидбека

Сохраняем [элемент], потому что он помогает [задача]. Нужно изменить [элемент], потому что сейчас он конфликтует с [пункт брифа]. Предлагаю [конкретная правка]. Приоритет: [критично / желательно / можно позже].

7. Структура итогового кейса

  1. Контекст проекта.
  2. Задача и ограничения.
  3. Креативная стратегия.
  4. Концепции для теста.
  5. Организация продакшена.
  6. План теста и правило решения.
  7. Результат или сценарий результата.
  8. Вывод и следующий шаг.

Финальная проверка

Откройте свой проект и удалите всё, что не помогает принять решение. В хорошем кейсе видно не количество текста, а ход мысли: почему выбрали такие концепции, как проверяли результат и что предложили делать дальше.
