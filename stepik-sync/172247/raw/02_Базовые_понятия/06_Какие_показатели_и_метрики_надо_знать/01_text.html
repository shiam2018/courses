Основные метрики и KPI в SEO

Чтобы понять, эффективны ли ваши вложения в SEO, важно регулярно измерять результаты. Для этого существуют специальные показатели — метрики (или KPI, Key Performance Indicators).

Вот основные метрики, которые должен знать начинающий SEO-специалист:

  1. Количество уникальных посетителей (посетители или уники).
    Количество отдельных пользователей, посетивших сайт за выбранный период.
  2. Количество посещений (визиты).
    Сколько раз пользователи заходили на сайт. Один пользователь может зайти несколько раз.
  3. Среднее время на сайте.
    Среднее количество времени, проведённого пользователями на сайте. Чем выше показатель, тем лучше.
  4. Глубина просмотра (среднее число страниц).
    Среднее количество страниц, просмотренных одним пользователем за визит.
  5. Коэффициент отказов.
    Процент пользователей, покинувших сайт после просмотра только одной страницы (Google) или менее 15 секунд (Яндекс).
  6. Позиция сайта в выдаче по ключевым словам. 
    Место сайта в результатах поиска по заданным ключевым словам. Отслеживается с помощью инструментов (например, SEMrush, Ahrefs).
  7. Количество внешних ссылок. 
    Сколько ссылок ведёт на ваш сайт с других ресурсов. Проверяется через Google Search Console или Яндекс Вебмастер.
  8. Коэффициент конверсии или CR (от англ. Conversion Rate).
    Процент пользователей, совершивших целевое действие (покупку, регистрацию).
    \[CR = Конверсии / Клики * 100\%\]
  9. Расходы (затраты)
    Сколько денег потрачено на продвижение сайта и его оптимизацию.
  10. Доход (Revenue)
    Деньги, заработанные благодаря SEO-продвижению (например, от продаж).
  11. Прибыль (Profit)
    Разница между доходом и расходами на продвижение.
  12. Стоимость целевого действия (CPA, Cost Per Action)
    Стоимость одной конверсии.
    \[CPA = Расходы / Конверсии\]
  13. Рентабельность инвестиций (ROI, Return On Investment)
    Показывает, насколько эффективно расходуются средства на продвижение.
    \[ROI = Прибыль / Расходы * 100 \%\]
