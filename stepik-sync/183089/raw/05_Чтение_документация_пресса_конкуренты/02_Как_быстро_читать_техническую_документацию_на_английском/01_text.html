Что будет на уроке?

Документация рекламных кабинетов, аналитических платформ и SaaS-инструментов написана по узнаваемым шаблонам — если знать эти шаблоны, читать её в разы быстрее.

Стратегия чтения: не читать документацию от начала до конца как книгу. Сначала пробежать заголовки (headings) и понять структуру раздела, затем искать конкретный ответ на свой вопрос — большинство документации пишется как справочник, а не как повествование.

Пример: «This feature is deprecated and will be removed in the next release. Use the new Campaigns API endpoint instead, which has a rate limit of 100 requests per minute» — расшифровывается как: старая функция скоро уберут, нужно перейти на новый endpoint API кампаний, у которого лимит 100 запросов в минуту. Каждое слово здесь — из таблицы выше.
