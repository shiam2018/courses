Этот уровень подходит для начинающих маркетологов, которые хотят закрепить базовые знания и навыки. Проект включает в себя выполнение ключевых шагов, достаточных для создания маркетинговой стратегии начального уровня.

Задания:

  1. Краткое описание проекта и его целей.
  2. Проведение базового исследования целевой аудитории (без создания портретов).
  3. SWOT-анализ конкурентов для понимания сильных и слабых сторон.
  4. Составление простого медиаплана для продвижения проекта с указанием базовых каналов и бюджета.
