Задание: Сбор семантического ядра из 100 запросов для SEO-продвижения

Цель задания:
Собрать семантическое ядро из 100 ключевых запросов для одного из бизнесов, почистить от нерелевантных запросов, разделить на кластеры по интенту и выделить 10 ключевых запросов для основного продвижения.

Шаги выполнения задания:

  1. Выбор бизнеса для продвижения

    • Выберите бизнес (например, интернет-магазин электроники, автосервис, кафе и т.д.), для которого вы будете собирать семантическое ядро.

  2. Сбор ключевых запросов в Яндекс Вордстат

    • Перейдите на сайт Яндекс Вордстат: https://wordstat.yandex.ru.
    • Введите несколько ключевых слов, связанных с выбранным бизнесом (например, если это автосервис, можно начать с запросов "ремонт автомобиля", "замена масла", "ремонт подвески").
    • Соберите минимум 100 запросов, которые отображаются по теме вашего бизнеса. Важно включить запросы с разной степенью коммерческой активности: информационные (например, "как заменить масло") и коммерческие (например, "купить запчасти для автомобиля").

  3. Чистка семантики от нерелевантных запросов

    • Пройдитесь по списку запросов и удалите "мусорные" или нерелевантные запросы, которые не соответствуют цели вашего продвижения. Например, если ваш бизнес автосервис, то запросы вроде "история автомобиля" или "рейтинг машин" будут лишними.
    • Оставьте только запросы, которые могут привести целевой трафик на сайт.

  4. Кластеризация запросов по интенту

    • Разделите запросы на группы по интенту (намерению пользователя):
      • Коммерческие запросы (намерение что-то купить, заказать или получить услугу): например, "ремонт двигателя цена", "автосервис Москва".
      • Информационные запросы (намерение узнать информацию): например, "как поменять масло", "почему шумит двигатель".
    • Пример кластеров:
      • Коммерческий кластер 1: "ремонт двигателя Москва", "ремонт коробки передач недорого".
      • Информационный кластер 1: "как заменить тормозные колодки", "что делать при перегреве двигателя".

  5. Добавление частотности запросов

    • Вернитесь в Яндекс Вордстат и для каждого запроса посмотрите его частотность (количество показов в месяц).
    • Добавьте частотность каждого запроса в таблицу для анализа важности и популярности запросов.

  6. Выделение 10 ключевых запросов

    • Из всех собранных запросов выберите 10 самых важных для продвижения (например, те, которые имеют высокую частотность и могут привести коммерческий трафик).
    • Эти запросы должны стать основными для вашего SEO-продвижения.

  7. Создание таблицы

    • Сформируйте таблицу (можно в Google Таблицах или Excel), которая должна содержать:
      • Столбец с ключевыми запросами.
      • Столбец с частотностью запросов.
      • Столбец с кластером (например, "Коммерческий", "Информационный").
      • Выделите 10 основных запросов для продвижения цветом.

  8. Результат работы

    • В результате у вас должна получиться таблица, разделенная на кластеры, с частотностью запросов и выделенными ключевыми запросами для продвижения.

Инструменты для работы:

  • Яндекс Вордстат: https://wordstat.yandex.ru
  • Google Таблицы или Excel
