Цель практики

Научиться собирать и обрабатывать семантическое ядро для бизнеса, а также формировать список ключевых слов для рекламной кампании в Яндекс Директ. Вы пройдете весь путь профессионального маркетолога: от начального сбора запросов до создания готового списка ключевых слов для контекстной рекламы.

Что вам предстоит сделать

  1. Выбрать бизнес для анализа
  2. Зарегистрироваться в сервисе Rush Analytics
  3. Составить семантическое ядро из 200 запросов
  4. Кластеризовать запросы по смысловым группам
  5. Вручную отобрать 50 наиболее перспективных ключевых слов для Яндекс Директа

Шаг 1: Определите бизнес для анализа

Используйте тот же бизнес, для которого вы уже делали бриф в модуле «База» и лендинг в модуле «Инструменты»: собранные здесь ключевые слова затем пригодятся для запуска рекламы на этот же сайт в следующей практике.

Если у вас пока нет своего проекта или вы хотите потренироваться на нише с большим объёмом запросов, выберите один из вариантов ниже:

  • Магазин мебели для дома
  • Курсы английского языка
  • Доставка правильного питания
  • Салон красоты
  • Юридические услуги для бизнеса
  • Строительство частных домов

Важно выбрать бизнес, который имеет четкую специализацию и целевую аудиторию.

Шаг 2: Инструменты для сбора семантики

  1. Зарегистрируйтесь на сайте Rush Analytics: это профессиональный онлайн-сервис для сбора и анализа ключевых слов
  2. Изучите бесплатный тарифный план и его возможности
  3. Ознакомьтесь с интерфейсом сервиса и его основными функциями
  4. Подготовьте дополнительные инструменты:
    • Яндекс Вордстат
    • Google Docs или Excel для работы с таблицами

Шаг 3: Сбор семантического ядра (200 запросов)

3.1. Базовый сбор запросов

  1. Определите 5-10 основных категорий товаров/услуг выбранного бизнеса
  2. Для каждой категории сформулируйте 3-5 базовых запросов (например, "купить диван", "мебель для гостиной")
  3. Войдите в Яндекс Вордстат и проверьте каждый базовый запрос:
    • Изучите статистику показов
    • Запишите объем по России за последний месяц
    • Сохраните запросы в таблице Excel/Google Docs

3.2. Расширение семантики через Вордстат

  1. Для каждого базового запроса изучите:
    • Раздел "Что еще искали люди, которые искали..." (правая колонка)
    • Раздел "Показов в месяц" (левая колонка)
  2. Отберите релевантные запросы и добавьте их в таблицу
  3. Используйте операторы Вордстата для более точного поиска:
    • Квадратные скобки [ ] для точного соответствия
    • Минус "-" для исключения слов
    • Кавычки " " для поиска фразы целиком

3.3. Использование Rush Analytics

  1. Создайте новый проект в Rush Analytics
  2. Импортируйте базовые запросы из вашей таблицы в веб-интерфейс
  3. Используйте функцию "Парсинг подсказок" для расширения списка запросов
  4. Запустите сбор частотности для всех запросов через веб-интерфейс
  5. Отфильтруйте запросы с нулевой частотностью
  6. Доведите общее количество запросов до 200

3.4. Дополнительные источники семантики

  1. Изучите подсказки в поисковой строке Яндекса
  2. Проанализируйте сайты конкурентов (разделы, категории, продукты)
  3. Используйте сервисы подбора запросов для контекстной рекламы

Шаг 4: Кластеризация запросов

  1. Проанализируйте собранные 200 запросов и определите логические группы (кластеры)
  2. Объедините запросы в кластеры по следующим критериям:
    • Общая коммерческая цель (информационные, транзакционные)
    • Тип товара/услуги
    • Географическая привязка
    • Цена/качество/другие характеристики
  3. Создайте в таблице отдельные листы для каждого кластера
  4. Присвойте каждому кластеру понятное название и краткое описание

Шаг 5: Отбор 50 ключевых слов для Яндекс Директа

  1. Проанализируйте каждый кластер и выберите наиболее перспективные запросы по критериям:
    • Коммерческий потенциал (намерение купить)
    • Частотность (объем поиска)
    • Конкуренция (сложность продвижения)
    • Сезонность
    • Соответствие целям бизнеса
  2. Отберите итоговые 50 запросов, которые будут использоваться для настройки рекламной кампании
  3. Для каждого выбранного запроса определите:
    • Тип соответствия (широкое, фразовое, точное)
    • Минус-слова
    • Средняя цена клика (примерная)
    • Рекомендуемый заголовок объявления

Что сдать в качестве результата

  1. Файл Excel/Google Таблицы со следующими листами:

    • Лист 1: Полное семантическое ядро (200 запросов) с частотностью и разбивкой по кластерам
    • Лист 2: 50 отобранных ключевых слов для Яндекс Директа с указанием типа соответствия и минус-слов
    • Лист 3: Обоснование выбора ключевых слов (краткое описание логики отбора)

  2. Краткий отчет (до 1 страницы), включающий:

    • Название и описание выбранного бизнеса
    • Основные выявленные кластеры запросов
    • Наиболее перспективные направления для рекламы
    • Трудности, с которыми вы столкнулись при сборе и обработке семантики
    • Ваши выводы о семантическом ядре выбранного бизнеса

Что дальше?

Собранная семантика: это топливо для следующей практики. В ней вы установите цели в Яндекс Метрике, свяжете её с Директом и запустите первую рекламную кампанию по 20 отобранным фразам.
