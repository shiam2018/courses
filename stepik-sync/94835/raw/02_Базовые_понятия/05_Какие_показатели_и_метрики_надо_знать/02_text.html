Также есть дополнительные метрики, которые позволяют быстрее оценить эффективность кампании, не проводя полного расчета рентабельности.

Наряду с метриками, которые показывают отношение расхода к результату, таких как CPM (расход на тысячу показов объявлений), CPC (расход на клик), CPA (расход на конверсию), мы можем рассчитать отношение дохода к результату. То есть посчитать eCPM (доход на тысячу показов), eCPC (доход на клик), eCPA (доход на конверсию).

eCPM  = Доход / Показы в тысячах

eCPC = Доход / Клики

eCPA = Доход / Конверсии

Такие метрики показывают "эффективное значение" показов, кликов и конверсий и позволяют быстро оценить прибыльность объявлений. С их помощью можно быстрее рассчитать ROAS, если мы считаем его по Доходу. 

ROAS = Доход / Расход * 100% = eCPM / CPM * 100% = eCPC / CPC * 100% = eCPA / CPA * 100%

Потому что:

Доход = eCPM * Показы в тысячах = eCPC * Клики = eCPA * Конверсии

Расход = CPM * Показы в тысячах = CPC * Клики = CPA * Конверсии
