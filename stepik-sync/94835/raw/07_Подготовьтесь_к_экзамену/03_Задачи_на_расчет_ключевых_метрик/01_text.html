Но все равно, рекомендуется прочитать этот пример решения, поскольку он относительно сложен и показывает взаимосвязь метрик интернет-маркетинга:

Задача:

У нас есть рекламная кампания в Яндекс.Директ, которую мы используем для продвижения нашей франшизы быстрого питания. Нужно рассчитать CPA, стоимость за конверсию, по следующим данным:

  • ROAS = 50%
  • CR = 5%
  • CPC = $50
  • Клики = 2500
  • Доход от одной конверсии (eCPA) = $750

Решение

Первый вариант расчета:

Чтобы найти CPA рассчитаем Расход, Прибыль, Доход и Конверсии, а затем поделим Расход на Конверсии:

  1. ROAS = Прибыль / Расход * 100% 
  2. Расход = CPC * клики = 50 * 2500 = 125 000
  3. Прибыль = Расход * ROAS / 100% = 125 000 * 50% = 62 500
  4. Прибыль = Доход - Расход
  5. Доход = Прибыль + Расход =  125 000 + 62 500 = 187 500
  6. Доход = Конверсии * eCPA 
  7. Конверсии = Доход / eCPA = 250
  8. CPA = Расход / Конверсии = 500

Или можно посчитать по-другому:

Так как Доход = eCPA * Конверсии, а Расход = CPA * Конверсии то  в формуле ROAS можно сократить Конверсии и найти CPA через eCPA и ROAS:

  1. ROAS = (eCPA - CPA) / CPA * 100% Умножаем обе части уравнения на CPA и делим на 100%  
  2. ROAS / 100% * CPA = eCPA - CPA Переносим все что содержит CPA в левую сторону уравнения
  3. ROAS / 100% * CPA + CPA = eCPA Выносим CPA за скобки
  4. CPA (ROAS / 100% + 1) = eCPA  Делим обе части уравнения на (ROAS / 100% + 1)
  5. CPA = eCPA / (ROAS / 100% + 1) = 750 / (0.5 + 1) = 750 / 1.5 = 500 Находим значение CPA
