Какая выплата в рублях по условию "Активный игрок 1" по офферу "War Thunder" (ID оффера в Admitad – 6448)?


Чтобы найти значение

  1. Перейдите в верхнем меню "Программы" --> "Каталог программ"
  2. Введите в поиске раздела "Основной фильтр" название оффера "War Thunder"
  3. Найдите значение выплаты по офферу в разделе "Тарифы" (то, что размыто на скриншоте)
  4. Введите значение в поле ответа в Stepik (только цифры, без "р.")
