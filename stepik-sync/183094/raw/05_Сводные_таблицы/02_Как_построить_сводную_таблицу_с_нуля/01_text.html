Что будет на уроке?

Сводная таблица за несколько кликов отвечает на вопрос «сколько по каждой группе», на который формулами СУММЕСЛИ пришлось бы отвечать отдельно для каждого значения канала.

Встаньте в любую ячейку таблицы «Данные» → «Вставка» → «Сводная таблица» → Excel сам определит диапазон данных → «ОК». Справа появится панель с четырьмя зонами: «Строки», «Столбцы», «Значения», «Фильтры». Перетащите «Канал» в «Строки», а «Расход, ₽» в «Значения» — за секунду получится таблица: сумма расхода по каждому из пяти каналов, без единой формулы СУММЕСЛИ, которую пришлось бы писать пять раз для пяти каналов вручную.

По умолчанию сводная таблица суммирует числовые поля. Чтобы посчитать количество кампаний вместо суммы расхода — кликните по стрелочке рядом со значением в зоне «Значения» → «Параметры полей значений» → «Количество». Так же легко добавить второе измерение: перетащите «Статус» в «Столбцы» — таблица разложится на сетку канал × статус, показывая расход по каждой комбинации сразу.

Хорошо / плохо: строить пять отдельных формул СУММЕСЛИ под пять каналов и вручную обновлять их, если появится шестой канал — плохо, потому что при изменении данных нужно не забыть добавить формулу. Построить одну сводную таблицу и нажать «Обновить» (правая кнопка мыши → «Обновить») при любом изменении исходных данных — надёжнее и требует одного действия вместо пяти формул.
