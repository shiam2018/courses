Что будет на уроке?

Три формулы для работы с текстом, которые нужны почти в каждой таблице: собрать текст из нескольких ячеек и разобрать его обратно на части.

СЦЕПИТЬ(текст1; текст2; ...) склеивает значения ячеек в одну строку: =СЦЕПИТЬ(C5;"_";D5) из кода канала и названия кампании соберёт единый идентификатор. Современный аналог — просто знак &: =C5&"_"&D5 делает то же самое короче, и Excel рекомендует его вместо СЦЕПИТЬ в новых файлах.

Обратная задача — разобрать текст на части. ЛЕВСИМВ(текст; количество_знаков) берёт символы слева, ПРАВСИМВ — справа. На листе «Данные» название кампании выглядит как YD_202603_01 — код канала, месяц и порядковый номер через подчёркивание. Первые два символа — код канала: =ЛЕВСИМВ(D5;2). Последние два — номер кампании внутри месяца: =ПРАВСИМВ(D5;2).

Хорошо / плохо: держать код канала в отдельном столбце C — хорошо, потому что по нему легко фильтровать и делать ВПР. Хранить его только «внутри» текста названия кампании (как часть D5) и надеяться, что при случае получится вытащить через ЛЕВСИМВ — плохо: сработает, пока формат названия не поменяется хотя бы в одной строке, и тогда формула молча вернёт неверный результат без предупреждения об ошибке.
