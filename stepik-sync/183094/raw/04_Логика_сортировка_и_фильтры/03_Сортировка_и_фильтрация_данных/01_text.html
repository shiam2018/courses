Что будет на уроке?

Как за пару кликов увидеть нужный срез таблицы из 180 строк, не трогая формулы вообще.

Сортировка: выделите таблицу (или просто встаньте в любую её ячейку), вкладка «Данные» → «Сортировка». Можно сортировать по одному столбцу (например, по расходу — от большего к меньшему, чтобы сразу увидеть самые дорогие кампании) или сразу по нескольким уровням: сначала по каналу, затем внутри каждого канала — по дате. Это меняет физический порядок строк в таблице — если нужно временно посмотреть срез, не трогая исходный порядок, лучше использовать фильтр, а не сортировку.

Фильтр: «Данные» → «Фильтр» добавляет стрелочки в заголовки столбцов. Клик по стрелочке в столбце «Статус» и выбор только «Активна» скрывает (не удаляет) остальные строки — таблица показывает только активные кампании, но данные всех строк остаются на месте. Можно комбинировать фильтры сразу по нескольким столбцам: канал = VK Реклама И статус = Активна — получится точный срез без единой написанной формулы.

Хорошо / плохо: отсортировать таблицу вручную, чтобы «на глаз» найти топ-5 кампаний по расходу — плохо: при добавлении новых строк порядок не обновится сам, и через месяц отчёт покажет уже неактуальный топ. Использовать фильтр или формулу МАКС/сортировку заново при каждом обновлении данных — надёжнее, потому что явно видно, когда и на каких данных был построен срез.

Внизу под отфильтрованной или отсортированной таблицей строка автосуммы (в правом нижнем углу листа, при выделении диапазона) сразу показывает сумму, среднее и количество видимых строк — без единой формулы, только по выделенному фрагменту.

Что дальше?

Дальше — условное форматирование: как сделать, чтобы таблица подсвечивала важные строки сама, без ручного просматривания.
