Что будет на уроке?

Claude Code — инструмент, через который я пишу код каждый день, включая сайт cleanor.app. Расскажу, как он устроен и почему терминал — не недостаток, а осознанный выбор для реальных проектов.

Агент, который живёт в вашем проекте, а не в отдельном окне

Claude Code запускается прямо в командной строке внутри папки проекта. Это значит, что агент видит всю структуру файлов, может открыть и прочитать любой из них, написать изменение, запустить тесты или сервер, посмотреть на ошибку в консоли и исправить её — весь цикл «написал → проверил → поправил» без вашего постоянного участия на каждом шаге.

Разница с чат-ботом, в который вы копируете код: там вы вручную переносите фрагменты туда-сюда. Здесь агент работает прямо с файлами вашего проекта — быстрее и с меньшим риском что-то потерять при копировании.

Для чего это подходит лучше всего

  • Проекты с реальной, растущей кодовой базой — не одна страница, а сайт или сервис с десятками файлов
  • Многошаговые задачи — «добавь фичу, которая трогает три разных файла» агент выполнит за один заход, а не по кусочкам
  • Задачи, которые можно объективно проверить — запустить, посмотреть на результат, сравнить с ожиданием

Как я на самом деле работаю с ним на cleanor.app

Типичный цикл: описываю задачу («добавь на страницу инструмента блок с примерами использования»), даю немного контекста (где похожие блоки уже реализованы), прошу показать план перед тем как менять код, затем — проверяю результат в браузере сам, прежде чем отправлять правку дальше. Ключевой момент: я не проверяю каждую строчку кода — я проверяю, что фича реально работает так, как задумано.

Разумные ожидания

Терминал — не самая дружелюбная среда для тех, кто никогда его не открывал: первое время придётся привыкать. Взамен вы получаете инструмент, который не имеет искусственных ограничений на размер проекта, в отличие от многих визуальных no-code конструкторов.
